VieLotusIM (Sen Việt)

Vietnamese input method. This repository contains the macOS Swift engine and InputMethodKit app, and the C++20 Windows and Linux engines and adapters.

Source repository · Releases · Upstream contributions · Tiếng Việt

Repository scope

  • macOS: Swift engine, InputMethodKit app, tests and CLI regression suite.
  • Windows and Linux: C++20 engine and native input method adapters.
  • iOS and Android app projects are distributed separately and are not in this repository.

Build

swift build
swift test
swift run VieLotusCLI --benchmark --json

Regression suite

The checked-in 9,091-case primary suite currently passes 9,091/9,091. In the symmetric no-context replay, 365/373 (97.86%) pass; the unique-path preservation group passes 180/180 (100%). These figures describe the checked-in CLI suite, not behavior in every app or device. Run the command above to reproduce them.
