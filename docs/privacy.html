Privacy

This notice covers source and services linked from this repository. It does not describe the separately distributed iOS and Android apps.

Typing and settings

The input engine processes text locally. The macOS app stores user settings locally. The source logger is debug-only and records event codes, lengths, and offsets rather than typed text. Review the specific build you install; this source description does not verify every third-party package or build.

Updater

The macOS updater contacts GitHub Releases when a user opens update settings or requests a check. It downloads an installer only after the user starts an update. GitHub receives the request and its standard connection data.

Feedback

The website feedback form sends submitted reports to its configured API. The included server function can store report type, platform and version details, typed keys, actual and expected output, target app, message, optional email, and request user-agent in Cloudflare D1. When configured, attachments are stored in Cloudflare R2; Turnstile may be used for spam checks. The repository does not specify a retention period.

The macOS app does not submit feedback in the background. If the user chooses GitHub, email, or Zalo actions, the report can include the entered keys and outputs, app/version/OS details, selected diagnostic settings, macros count and app overrides. GitHub/email drafts may put report content in a URL; the app also copies the report to the clipboard. Review it before proceeding.
