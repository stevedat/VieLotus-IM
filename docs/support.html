Installation

Download installers from the latest GitHub Release. Check the release notes for supported versions and architectures.

macOS

Install VieLotusIM.pkg. Then add Sen Việt in System Settings → Keyboard → Text Input → Edit.

Windows

Download the x64 or ARM64 installer listed in Releases. After installation, choose Sen Việt from the Windows input method selector.

Linux

Download the Debian package matching your architecture from Releases or use the Launchpad PPA instructions. The repository also contains source build instructions.

iOS and Android

Install from the App Store or Google Play. These application projects are maintained outside this repository.

Report an issue

Use GitHub Issues or the feedback form. Review any text, diagnostics, or files before submitting.
