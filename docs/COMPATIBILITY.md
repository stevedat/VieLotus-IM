# Compatibility and verification scope

This repository contains source for the macOS InputMethodKit app, Windows TSF adapter, and Linux IBus/Fcitx5 adapters. The root README links to current installers and package instructions.

A successful source build or CLI benchmark does not establish compatibility with every OS version, architecture, terminal, browser, Electron app, editor, or text field. Test each target host on the actual OS version before documenting it as verified.

iOS and Android applications are distributed separately; their app projects are not included here.
