# Ecosystem & Upstream Contributions

[Tiếng Việt](ECOSYSTEM_CONTRIBUTIONS.vi.md)

While testing Vietnamese syllable orthography and bilingual boundary cases across desktop and Linux input methods, we submit reproducible bug reports, patches, and unit tests upstream to peer open-source projects. Each pull request is written independently for the target repository's architecture and license.

> Status badges below query the GitHub API directly (`open` / `merged` / `closed`).

## 3. Regression Coverage in VieLotusIM

The edge cases listed above are covered by unit tests in both the Swift (`Sources/VieLotusCore`) and C++20 (`Sources/VieLotusCoreWindows`) engines. On the checked-in CLI benchmark (`swift run VieLotusCLI --benchmark --json`), the current snapshot passes 9,091 / 9,091 (100.00%) on the primary suite, 365 / 373 (97.86%) on symmetric no-context collisions, and 180 / 180 (100.00%) on unique Vietnamese paths (`whitelist_safe = never`). These figures describe the checked-in regression suite, not behavior in every application or device; see [`BENCHMARK_REPORT.md`](BENCHMARK_REPORT.md) and [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).
