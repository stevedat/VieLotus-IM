# Changelog

This file contains historical notes. Current source scope and build instructions are in the [README](../README.md).

## v1.0.0 — 2026-10-12

The original release notes described a combined macOS and mobile product. They included claims about offline behavior, error rates, application compatibility, and mobile source that were not independently verified by the current public repository. They are not current verification results.

Current public source includes the Swift engine and macOS InputMethodKit app, plus C++20 engines and adapters for Windows and Linux. iOS and Android app projects are maintained separately. See [architecture](ARCHITECTURE.md), [benchmark results](BENCHMARK_REPORT.md), and [privacy](../PRIVACY.md).
